# The Haunted Garden — Scents From Beyond

An award-winning, luxury horror scrollytelling web experience and occult fragrance archive. Built with **React 19**, **Vite**, **GSAP ScrollTrigger**, **Lenis Inertia Scrolling**, **Tailwind CSS**, and **Three.js**.

---

## ✨ Features

- **Pinned Scrollytelling Runway**: Depth-controlled progression tracking descent into the 1894 historical estate.
- **Continuous Atmospheric Video Engine**: Full-bleed background video streaming with clean, watermark-free presentation.
- **Interactive Classified Case Dossiers**: Clickable case modals with incident logs, survivor testimonies, and olfactory coordinates.
- **Ambient Horror Sound Engine**: Synchronized horror voice track and atmospheric acoustic audio.
- **Luxury Editorial Design**: Glassmorphism (`backdrop-blur-md`), Google Fonts `Cinzel` display typography, and zero distracting gimmicks.
- **Lenis Smooth Inertia Scrolling**: Silky momentum scrolling across all desktop and mobile devices.

---

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/AbhijithJ1/haunted-garden.git
cd haunted-garden
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
